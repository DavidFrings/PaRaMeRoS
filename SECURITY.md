# Security Policy

## Supported versions

Only the latest release (and the `main` branch, which is what https://PaRaMeRoS.net runs) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of this repository and choose
**Report a vulnerability** ([direct link](https://github.com/DavidFrings/PaRaMeRoS/security/advisories/new)).
If that is not possible, send an e-mail to dev@davidfrings.dev.

Please include:

- a description of the problem and its impact
- steps to reproduce, ideally with a minimal example
- the affected version or commit

## What to expect

This project is maintained by a single person in their spare time, so everything here is best effort:

- I will acknowledge your report within about 7 days.
- I will keep you updated while I investigate and prepare a fix.
- Once a fix is released, the issue is disclosed publicly (and credited, if you wish).
